# 原入力を読んだ後に決める3つの境界

まず私有の6件原入力票だけを読み、各例の初回判断と根拠を残す。その後この3問へ進む。助手の提案やモデルの予測を答えの基準にしない。既承認MS4の採否を再質問するものではない。

| 境界 | 本人へ残す短い質問 | 記入 |
|---|---|---|
|AIツールの一般UI|AIツールそのものの端末描画・操作画面・アクセシビリティの実装も、AI機構の説明がなくても拾いますか？|含む / 含まない / 条件付き / 方針未決。条件・理由: ____|
|AI/ML専用基盤の一般管理|AI/ML専用基盤の権限・共有容量・管理境界も、具体的な学習や推論の説明がなくても拾いますか？|含む / 含まない / 条件付き / 方針未決。条件・理由: ____|
|物理設備|データセンターの冷却・省資源など、RSSにAI利用の説明がない物理設備の話題は拾いますか？|含む / 含まない / 条件付き / 方針未決。条件・理由: ____|

方針が決まっても、原入力だけで記事が該当するか分からなければ「情報不足」のまま残せる。タイトルが短いだけ、AIという語がないだけで、助手がNを確定するものではない。必要な製品背景を使った場合は「背景依存」とその内容を記録する。

初回の6件判断と、方針確定後に変化した判断を別に保存する。「情報不足」「方針未決」は注釈・監査の状態であり、新しいモデル学習クラスではない。モデルのuncertainとも同義ではない。

今回は票の準備まで。人間が未回答なら判断欄を空白のまま保ち、教師・gold・thresholdを書き換えない。将来集計する場合も既知教師・隔離・probeを含む歴史的監査なので、未見testの精度とは呼ばない。
